# Automation Scripts

Welcome to my automation scripts portfolio. This repository is an ongoing collection of Python tools I create to automate repetitive tasks and improve everyday workflows.

I started building these scripts to turn recurring manual processes into practical, reusable tools. The projects here also give me a place to explore automation, improve my Python skills, and document solutions that I can use again. This portfolio is still growing, and I will continue adding scripts as I find new tasks worth automating.

## Scripts

| Script | Description | Motivation |
|---|---|---|
| [Number Files](scripts/descriptions/number-files.md) | Renames the files in a directory with sequential, zero-padded numbers while preserving their file extensions. | I created this script to replace the slow and error-prone process of numbering files one at a time. |
| [Number CamScanner Files](scripts/descriptions/number-files-cam-scanner.md) | Renames CamScanner-style files from the number at the end of each original filename and applies a chosen starting offset. | I created this variation so scanned pages could be renumbered while keeping their existing page sequence. |
| [Incremental LeetCode Problem Export](scripts/descriptions/get-leetcode-problems.md) | Collects free LeetCode problems by category, appends unseen problems to CSV, and stages them in Google Sheets for controlled CSV downloads. | I created this pipeline to keep my study queue current without repeatedly exporting or importing the same problems. |
